# EquationForge

EquationForge is a local-first Microsoft Word add-in for creating mathematical equations and study material. It provides a lightweight MathType-style editor and inserts equations as native, editable Word mathematical notation (OMML).

## Current Release

**Version:** 1.0.0  
**Status:** Stable v1 baseline  
**Platform:** Microsoft Word desktop with Office Add-ins support  
**Technology:** TypeScript, Office.js, Webpack, Word OOXML/OMML

## Features

- Native editable Word equations using OMML/OOXML
- Fraction, nested fraction, radical and indexed radical notation
- Superscripts, subscripts and combined scripts
- Prime notation such as `f'(x)`, `f''(x)` and `f'''(x)`
- Integrals, contour integrals, summations, products and other n-ary operators
- Complex n-ary limits and differentials such as `\int_0^1 x^2\,\dd{x}`
- Greek letters and common mathematical symbols
- Trigonometric, logarithmic and related functions
- Inverse trigonometric notation such as `\\arcsin`, `\\arccos` and `\\arctan`
- Dynamic delimiters with `\\left ... \\right`
- Matrices: `matrix`, `pmatrix`, `bmatrix`, `Bmatrix`, `vmatrix`, `Vmatrix`
- Piecewise/cases expressions
- Aligned and gathered equations
- Accents such as hats, bars, vectors and dots
- Overbrace and underbrace
- Overset and underset
- Binomial notation
- Boxed equations
- Text blocks inside equations
- Bold, roman and italic mathematical styles
- Explicit mathematical spacing commands
- Equation preview
- Font selection and font-size selection
- Insert, edit, replace and edit-selected-equation workflows
- Equation source stored with EquationForge content controls for later editing

## First-Time Local Setup

Clone the repository and enter the project directory:

```powershell
git clone https://github.com/DLSiem/EquationForge.git
cd EquationForge
```

Install dependencies:

```powershell
npm install
```

You normally only need to run `npm install` once after cloning, or again when dependencies change.

## Run EquationForge Locally

Start the development server:

```powershell
npm start
```

Keep this terminal running while using the add-in.

The Office add-in uses the development server specified by the project manifest. Open/load the EquationForge manifest in Word using the normal Office Add-ins sideloading/developer workflow for your Word installation.

Once the add-in is loaded, open the EquationForge task pane and enter an equation. The preview updates as you type. Use **Insert Equation** to insert the result into Word as editable mathematical content.

### Important development note

Normal TypeScript, HTML and CSS edits are picked up by the development workflow. Restart the development server when you change project configuration, the manifest, package configuration, or another file that requires a new server/build configuration.

## Editing Equations in Word

EquationForge stores its source expression in an EquationForge content-control tag when an equation is inserted. This allows the add-in to reload the original source for editing.

Typical workflow:

1. Insert an equation.
2. Use **Edit Last** to reload the most recently inserted EquationForge expression.
3. Modify the expression.
4. Use **Replace** to update the existing equation.
5. Alternatively, select an EquationForge equation in Word and use **Edit Selected**.

## Fonts and Sizes

The editor currently exposes several common fonts, including:

- Arial
- Times New Roman
- Cambria Math
- Calibri
- Georgia

The renderer applies the selected font and configured size to the generated mathematical content. Font availability and visual appearance can still vary according to the fonts installed on the local Windows system.

## Troubleshooting

### `npm` is not recognized

Install Node.js and reopen PowerShell so the Node.js installation is available on `PATH`.

### The add-in does not start

Check that:

- `npm install` completed successfully.
- `npm start` is still running.
- Word can reach the local development server.
- The correct `manifest.xml` is loaded in Word.

### Changes are not visible

Confirm that the development server is still running. Restart `npm start` after configuration or manifest changes.

### Equation insertion fails

First try a simple expression:

```text
x+y=z
```

Then check the browser/Office developer console for the parser or OOXML error. Test the expression with the smallest structure needed to isolate the problem.

### A supported command reports `Unsupported command`

Check that the command has been added to the parser and that the input uses EquationForge's supported syntax. The project intentionally supports a practical mathematical subset rather than full LaTeX compatibility.

Keep the stable v1 source in Git and tag releases.

```powershell
git tag -a v1.0.0 -m "EquationForge v1.0.0"
git push origin main
git push origin v1.0.0
```

Create a clean source archive from the tag:

```powershell
git archive --format=zip --output="..\EquationForge-v1.0.0-source.zip" v1.0.0
```

Future features should normally be developed after the v1.0.0 baseline so the stable release can always be recovered.

## Development Principles

EquationForge is designed around a local-first architecture:

```text
User input
   ↓
Equation Parser
   ↓
Mathematical AST
   ↓
OMML Renderer
   ↓
Word OOXML
   ↓
Native editable Word equation
```

There is no requirement for a cloud backend or paid equation API for the core editor.

## Scope of v1

Version 1 focuses on a dependable Class 8–12 mathematical notation workflow, native Word equation insertion, editing and replacement, font control, and the most common algebra, calculus, matrix and function structures.

More advanced notation, productivity features and broader LaTeX compatibility can be added in later releases without changing the v1 baseline.
